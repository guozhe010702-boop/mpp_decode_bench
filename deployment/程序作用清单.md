| 部署附加项 | 作用 |
|---|---|
| install.sh / install.py | 校验payload、占用及冲突，复制到固定路径，不自启。 |
| install_system_deps.sh | 显式安装Ubuntu/Debian用户态依赖。 |
| check_board.sh | 只读板端架构/节点/传感器/库预检。 |
| manifest.json | 部署payload每文件SHA256、权限、软链接映射。 |
| low_latency/build/imx415_low_latency | 已验证ARM64二进制。 |
| runtime/bin/ffmpeg、ffprobe | 私有Rockchip工具，历史基准/码流检查；V3主链路不走FFmpeg。 |
| runtime/lib/librockchip_mpp.so* | 当前私有MPP库，软链接需保留。 |
| runtime/lib/librga.so*等 | SDK依赖，V3显示走DRM/VOP。 |
| runtime/include、静态库、pkgconfig | SDK开发头文件及链接资源。 |
| ffmpeg_pipeline/camera_control | 实际运行导入的辅助包，与工程dependencies源码快照对应。 |

系统另行提供：内核/BSP、RKAIQ及IQ、libdrm、glibc/libstdc++、systemd、Cairo/Pango、中文字体。mediamtx未加入包，默认本地链路无需它。
