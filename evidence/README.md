# 精简验收证据

这里保存V2/V3的性能摘要、逐分钟统计、码流格式探测结果和恢复测试结果，便于与项目报告交叉核对。

- `v3/endurance/`：最终60分钟统计、DMA输入计数、上游时间差及内存观察。
- `v3/comparison/`：双平面拷贝、连续NV12拷贝、DMA共享，以及H.264/H.265的交错对照。
- `v3/stress/`：HUD阻塞、处理阻塞及采集直接显示诊断。
- `v3/lifecycle/`：显示错误、手动启停和监督进程强制终止后的恢复。
- `v2/endurance/`：上一版本的60分钟摘要，保留原始统计口径。

JSON中的板端绝对路径和进程编号属于当时的实验元数据，并不表示这些路径和进程当前仍然存在。实验系列目录名沿用20261117，V3最终发布与60分钟测试完成于2026-11-18。
